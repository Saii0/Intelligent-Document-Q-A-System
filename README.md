# Intelligent-Document-Q-A-System
Developed a document-grounded question-answering backend using Java, Spring Boot, Spring AI, and OpenAI with a RAG workflow.
• Processed PDF documents with Apache Tika and TokenTextSplitter; used PostgreSQL and PGVector for embedding storage and semantic similarity search.
• Implemented chat memory, metadata filtering, citations, Swagger/OpenAPI documentation, and Docker-based containerization.
• Exposed REST APIs for document ingestion and question answering, enabling users to upload PDFs and retrieve context-aware responses.
